# EduProgress

EduProgress — навчальна вебплатформа для перегляду курсів, проходження тестів і відстеження прогресу студентів.

Проєкт розроблено в межах курсової роботи з дисципліни «Веб-технології та веб-дизайн».

## Основні можливості

- Реєстрація та авторизація користувачів.
- Розмежування ролей студента й викладача.
- Перегляд навчальних курсів і уроків.
- Позначення уроків як завершених.
- Проходження тестів та автоматичне оцінювання відповідей.
- Збереження результатів тестування.
- Відстеження навчального прогресу.
- Створення та редагування навчальних матеріалів викладачем.
- Перегляд результатів студентів.
- Підтримка світлої та темної тем інтерфейсу.

## Використані технології

- **C#** — мова програмування серверної частини.
- **ASP.NET Core 8 MVC** — фреймворк для розроблення вебзастосунку.
- **Entity Framework Core** — робота з базою даних.
- **ASP.NET Core Identity** — авторизація та керування ролями.
- **MySQL 8.0** — зберігання даних.
- **HTML, CSS, JavaScript** — створення інтерфейсу.
- **Bootstrap 5** — оформлення та адаптивність сторінок.

## Вимоги для запуску

- Windows 10 або Windows 11.
- .NET SDK 8.0.
- MySQL Server 8.0.
- Visual Studio Code або інший редактор коду.
- Веббраузер (Google Chrome, Microsoft Edge тощо).

## База даних

Для зберігання курсів, уроків, користувачів і результатів тестування EduProgress використовує MySQL 8.0.

Перед запуском застосунку необхідно:
1. Встановити та запустити MySQL Server.
2. Налаштувати рядок підключення в `appsettings.Development.json`.
3. Застосувати міграції Entity Framework Core:

```powershell
dotnet ef database update
```

4. Налаштуйте підключення застосунку до бази даних у файлі `appsettings.Development.json`.

## Запуск проєкту

1. Завантажте репозиторій:

```powershell
git clone 
```

2. Перейдіть до папки проєкту, у якій розташований файл `EduProgress.csproj`.

3. Відновіть залежності:

```powershell
dotnet restore
```

4. Переконайтеся, що MySQL запущений, а підключення до бази даних правильно налаштоване.

5. Застосуйте міграції Entity Framework Core:

```powershell
dotnet ef database update
```

6. Запустіть вебзастосунок:

```powershell
dotnet run
```

7. Відкрийте в браузері адресу, яку покаже термінал у рядку `Now listening on:`.


## Тестування

Для перевірки роботи EduProgress проведено:

- Функціональне тестування основних можливостей.
- Перевірку адаптивності інтерфейсу.
- Оцінювання швидкодії за допомогою Lighthouse.
- Навантажувальне тестування за допомогою k6.
- Перевірку швидкодії SQL-запитів на різних обсягах даних.

### Навантажувальне тестування

Для запуску тесту необхідно встановити k6 та запустити EduProgress локально.

У папці проєкту виконайте:

```powershell
k6 run load-test.js
```

За замовчуванням тест використовує 5 віртуальних користувачів протягом 30 секунд.

Для перевірки з 10 або 25 користувачами:

```powershell
k6 run --vus 10 --duration 30s load-test.js
k6 run --vus 25 --duration 30s load-test.js
```
